# 019-C 一手证据闭合率

冻结日期：2026-07-25。本文档提交后，测量期间不得修改指标定义、题目分母或阈值。

## 名称与测量对象

指标名称为 **Agent 一手证据正文闭合率（Agent Primary-Body Evidence Closure, APBEC）**。它衡量修复后的 Agent 从查询生成、能力选择、检索到 `web_fetch` 的端到端链路，实际取得的一手来源正文对题面原子口径的覆盖。

它与 019-B 的可达性指标不是同一个指标：019-B 衡量固定人工查询的 Tavily 前五条原始召回是否可达，APBEC 衡量 Agent 自生成查询后实际抓取的一手正文是否闭合题面口径。APBEC 不替代、不覆盖、不重评 019-B 的 `REACHABLE=2 < 4` 与 STOP。

## 一手来源

可接受来源必须是下列主体直接发布的正文：

1. 题面公司或交易参与方的官网、投资者关系页或公告；
2. 证券交易所、法定披露平台、政府或监管机构；
3. 题面所指行业协会、统计机构或原始研究机构；
4. 事件组织方或直接参与方对该事件的正式发布。

媒体转述、内容平台、百科、数据库营销页、报告销售页、搜索结果摘要和转载均不是一手正文。域名只是候选特征，最终仍须由发布主体与正文内容共同确认；公司官网、`.gov.cn`、交易所/法定披露域名、协会或原始研究机构域名可作为候选。

## 闭合定义

一个原子口径只有同时满足以下条件才记为 `1`：

1. URL 由修复后的 Agent 查询生成与能力选择链路获得；
2. `web_fetch` 成功返回该 URL 的发布方正文，不使用 Tavily snippet 代替；
3. 正文中出现题面所需的数字与口径词，或事件、日期与“规划/执行”等必要限定；
4. 公开结果记录 URL、正文命中字符区间、至多 1,000 字符摘录和完整抓取正文 SHA-256。

抓取失败、只命中二手转述、数字存在但口径词缺失、或事件存在但无法区分倡议与执行，均记为 `0`。

## 公式与冻结阈值

单题闭合率：

`question_closure(q) = closed_atomic_requirements(q) / fixed_atomic_requirements(q)`

六题宏平均：

`APBEC = Σ question_closure(q) / 6`

通过阈值同时满足：

1. `APBEC >= 2/3`；
2. 至少 `4/6` 道题的 `question_closure >= 2/3`。

阈值理由：宏平均避免原子口径较多的题目支配结果，`4/6` 约束防止少数易题掩盖多数题失败；`2/3` 要求每道达标题至少闭合主要数字/事件与一项关键口径边界，而不是仅命中题面名词。

## 测量上限

- Tavily 查询最多 18 次，每题固定 3 次；
- HTTP 抓取最多 30 次；
- 不调用任何 LLM provider；
- 原始正文仅写入 `.gitignore` 覆盖路径；公开材料只保留域名、URL、至多 1,000 字符命中摘录与 SHA-256。
