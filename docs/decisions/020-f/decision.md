# 020-F：证据链四处断点修复

## 决策

- 重规划查询改为结构化字段拼装；标题文本不再作为检索词来源。守卫上限为中文 48 字符、与标题的最长公共子串 12 字符，并要求目标文档类型词元。
- 缺失 Critic 结果时，报告显示“未执行”，不渲染任何质量数值。
- 来源日期解析依次读取 HTML meta、JSON-LD、URL/正文日期；PDF 从已解码的正文头部读取。解析失败为 `unknown`，绝不使用 epoch。unknown 的 freshness 为中性：不产生虚假 freshness gap。
- 确定性报告路径此前未经过 019-B 的 LLM 渲染去重逻辑；现与其一致地去除已在关键发现中出现的明细，并把无法关联的证据放入“补充事实”。

## 不利事实与边界

- 非金融遗留计划未提供结构化实体字段时，重规划使用显式低特异性占位字段“研究主体 / 事项”，不会回退复制标题；这保持离线默认路径可运行，但不应被视作金融查询质量证明。
- 本轮无网络、无 LLM provider 调用、无金钱成本。
- 默认输出内容因读者可见缺陷修复而改变，两个冻结 characterization 资产按版本化规则一并更新；没有修改旧版历史记录。
