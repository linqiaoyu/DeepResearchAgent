# 025 决策记录：真实年报可达性与财务链路

## 已证实事实

- 通过生产 `CninfoDisclosureSource` 于 2026-07-26 进行了 3 次 HTTP 请求，取得贵州茅台 2025 年年度报告（公告日 2026-04-16；CNINFO URL 在受管 fixture 对应下载脚本输出中）。原件为 143 页、约 1.0 MiB，存于 `tests/fixtures/`，未以合成 PDF 替代。
- 生产默认值是 `pdf_max_pages=100`、`char_limit=40_000`。该原件中，100 页解码为 107,162 字符，交付下游为 40,000 字符，在 PDF 第 40 页的第 1,861 / 3,304 字符处截断。因此 R1 判定为 **(b) 截断导致主要财务报表不可达**。
- 财务意图下的新页选择策略先取命中锚点的页和相邻页，再在同一 40,000 字符预算内交付；不是无条件增大预算。真实原件的修复前后分别为 40,000 / 30,645 字符，修复后合并利润表、营业收入、营业成本和归母净利润均进入窗口。
- procedural memory 只采用同一确定性 question type 下已标记 `sufficient` 的最高分历史策略，并形成 `procedural_memory_read` 决策。无记录时不改变计划，冻结快照保持零变化。
