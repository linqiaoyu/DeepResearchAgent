# 019-B 对 019-C 的影响

## 决策结论

019-B 进入预登记分支 B：六题中 `REACHABLE=2`、`PARTIAL=4`、
`UNREACHABLE=0`。B0–B7 的零成本工程工作可以记为 COMPLETE，但 019-C
必须 STOP 交 PM。若不先解决检索可达性，019-C 的负面结论将无法归因：
fact accuracy 下降既可能来自 Agent，也可能仅因 Tavily 未直达一手披露。

本文件不修改 019-C 的预登记支出上限，也不替 PM 选择处置路线。

## 已改变的设计事实

1. Q01、Q04 可由 Tavily 命中公司官网年报，适合保留为 provider 可达性对照。
2. Q16、Q19、Q26、Q28 只能部分闭环：数字或事件大多可从二手材料召回，
   但一手原文、同期进展或企业实际执行至少缺一环。
3. 重规划确定性臂不再携带 `resolve`、issue type、置信度诊断等内部词；
   因此未来双臂比较不再由明显的查询污染造成起点不公平。
4. LLM 报告读者层现已机械阻止科学计数法、原始期间键与同一金融事实重复；
   未来真实模型验证仍须评估内容质量，但无需再把这三类确定性渲染缺陷计入
   模型判断质量。
5. 当前只存在 strict byte-for-byte replay。strategy replay 未实现，019-C
   不得把宽松/意图级回放列为已具备能力或验收前提。

## 交 PM 的可选处置与范围估计

以下均为估计，不是实施授权。

### 方案 1：更换或增加检索 provider

- 预计范围：3–5 个实现/配置/测试文件，约 120–220 行生产代码；另需用相同
  18 条查询做一次零 LLM provider 对照。
- 优点：对六题统一改善，无需改变研究问题。
- 风险：新 provider 的中文公告覆盖、原文抓取、费用和数据留存边界均须重新
  预登记；不同 provider 排名差异会成为新混淆。

### 方案 2：增加一手源直连

- 预计范围：首批可选 2 类来源（交易所/巨潮与公司公告）共 4–7 个
  实现/契约/fixture/测试文件，约 180–320 行生产代码；若把行业协会与海外
  工厂官方渠道也纳入，可能超过单卡 350 行，应拆卡。
- 优点：直接解决 Q16/Q19/Q26/Q28 的一手闭环缺口，归因最清晰。
- 风险：反爬、PDF/公告格式、超时/重试和许可边界需要单独验证；不得在
  019-C 付费实验中临时边跑边接。

### 方案 3：替换四道 PARTIAL 题

- 预计范围：2–4 个题集/预登记/审计文档，不要求生产代码；需要重新冻结题面、
  缺口口径与判分规则。
- 优点：最快恢复可归因实验。
- 风险：改变目标总体，可能只证明“易检索题”有效；必须保留 Q01/Q04 作为锚点，
  并显式申报题集替换对外推性的影响。

## 建议的 PM 决策顺序

先决定 019-C 是要验证“现有 Tavily 边界内的 Agent 增益”，还是要验证“对真实
A 股一手披露的研究能力”。前者可考虑替题；后者应优先评估一手源直连，再决定
是否增加 provider。无论选择哪条路线，都应先重跑六题可达性门禁，只有
`REACHABLE >= 4` 才恢复 019-C 的付费授权。
