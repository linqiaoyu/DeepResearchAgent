Status: COMPLETE

## Decision

Pre-writing selection is no longer first-arrival order. Within each
sub-question it preserves a bounded four-cell numeric matrix, prioritizing
period match, explicit subject match, distinct subject/unit pairs, question
overlap, and confidence. A selected numeric Evidence item is delivered when
its typed value or any percentage stated in its claim is absent from reader
prose, even if another item from the same source already made the footnote
reachable.
